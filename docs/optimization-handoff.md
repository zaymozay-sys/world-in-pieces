# Оптимизация и переработка кода: что сделано и как продолжить

Документ для того, кто продолжит работу (в том числе другая модель). Читается без истории переписки.
Состояние на 15.11.2026: версия в `package.json` — 2.3.8 (не менять без просьбы владельца), поверх тега `v2.3.8` лежат 12+ коммитов оптимизации. В коде они помечены «2.3.9».

## Правила владельца (обязательны)

- Отвечать по-русски, коротко. Экономить лимиты: не читать большие файлы целиком, искать `grep`-ом.
- Картинку не ухудшать: никаких уменьшений и пережатий картинок, никаких изменений внешнего вида. Любую правку стилей и отрисовки проверять `tools/visual-diff.js`.
- Версию не менять и релиз не делать, пока владелец прямо не попросит. `git push` невозможен (403) — коммиты локальные. GitHub не предлагать привязать.
- Релиз для GitHub оформляется по `HANDOFF.md` (правила в начале файла): архив изменённых файлов (< 100 файлов в части), полный архив, `HANDOFF.md` отдельно, раздел в `docs/design.md`.
- Промты для картинок — только в артефакте владельца «Арт-промты», не в файлах репозитория.
- Игроков нет, только тестеры: сохранения можно пересчитывать.

## Как проверять каждую правку

```
npm test                                   # правила, линтер, анимации (обязательно, должно быть exit 0)
python3 -m http.server 8002 &              # текущий код
git worktree add /tmp/base <коммит-до>     # прежний код
(cd /tmp/base && python3 -m http.server 8001 &)
node tools/visual-diff.js http://localhost:8001/ http://localhost:8002/     # «Отличий нет.»
PHASE=0.5 SCENES=scr-medals node tools/visual-diff.js ...                   # середина анимаций, выбранные экраны
node tools/perf-runtime.js http://localhost:8002/                           # занятость процессора по экранам
node tools/perf-profile.js idle "http://localhost:8002/#dev-fight-wolf-3-solo" 1366 768   # какие функции заняты
```

Замеры нельзя запускать одновременно с e2e-тестами: цифры и снимки «плывут» (ложные отличия в `result-win`).
Экраны открываются адресами `#dev-…` (список — в начале `js/devjump.js`).

## Что осталось (по убыванию пользы)

1. **Бой в покое** — сделано: тень под мобом теперь отдельный слой `.mob-shadow` (ставит `mobShadow` в `js/boot.js`, стили — рядом с `mob-bob` в `css/style.css`). Высота верхней полосы боя больше не измеряется каждые 400 мс (`watchBarH` в `js/duo.js`). Осталось 8% (телефон) и 14% (компьютер): это сами кадры анимаций (искры в швах поля, качание моба) — браузер обслуживает их в основном потоке даже при отрисовке на видеокарте; дальше снижать можно только убирая анимации, то есть меняя картинку. Можно разобрать через `SEED=1 WAIT=24000 node tools/perf-profile.js idle "…#dev-fight-wolf-3-solo" 1366 768`.
   Находка (поведение не менял): после первого удара по мобу класс `hurt` с портрета не снимается (`js/game.js`, строка с `classList.add('hurt')`), поэтому моб перестаёт качаться до конца боя. Так было и в 2.3.8. Спросить владельца, задумано ли это.
2. **Запуск: `cull` в `js/mapview.js` ≈ 300 мс (×4)** — карта сначала рисуется с камерой по умолчанию и прячет «не те» куски, потом камера встаёт на героя. Пробовал поставить камеру до `renderStatic()` в `load()`: `cull` из замера исчез, НО обучение стало подсвечивать другого зверя (выбор цели зависит от положения камеры в момент отрисовки) — правку откатил. Сначала разобраться, как обучение (`js/tutorial.js`, подсветка первого зверя) выбирает цель, и сделать выбор независимым от камеры.
4. **Картинки боя грузятся на карте** (заклинания 266 КБ, предметы 193 КБ — панель боя строится при запуске в `js/boot.js`, `buildSpellbar()`). Можно подключать `src` после события `load`, но не «лениво»: в первом бою значки не должны появляться с задержкой.
5. **Крупные файлы** (план — в `docs/architecture.md`, раздел «Куда расти»): `js/game.js` — тело одной функции `createBattle(host)`, резать по разделам нельзя; выносить по одному куску то, что не трогает состояние боя. `js/screens.js` — одно замыкание, выносить окна по одному. После каждого выноса: `npm test` + полный `visual-diff`.
6. **Мелочи**: 57 предупреждений линтера (`npx eslint js`) — неиспользуемые переменные; `lootshine` в `css/style.css` перекрыта `rwShine` и не работает — можно убрать; `newspell`, `hintPulse`, `coachPulse` — тяжёлые, но редкие анимации (список исключений в `tools/audit-anim.js`).
7. **Не начато из прежних задач**: траты варианта В в экономике (решили не вводить — доля дохода на комплект 14–53%), медали за осаду, Башню и Маяк (нет счётчиков), значки `medal-elite|hatch|arena|pvp` ждут картинок владельца, старые `docs/art-prompts-*.md` — спросить владельца, что убрать.
