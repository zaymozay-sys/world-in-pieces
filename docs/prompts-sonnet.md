# Промты для Sonnet 5.5: уровни существ; усиления вещей, эликсиры и рецепты

Два самостоятельных промта. Каждый вставляется в чат целиком. В обоих первый шаг — разбор и предложение без правок кода: решения по игре принимает владелец.

Общие правила (повторены в каждом промте, чтобы его можно было вставить отдельно): отвечать по-русски и коротко; версию не менять, релиз и `git push` не делать; картинки не трогать; промты для картинок — только в артефакте владельца «Арт-промты»; игроков нет, только тестеры — сохранения можно пересчитывать.
