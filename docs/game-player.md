# Автоматический игрок для «Хрупкого мира»

Это браузерный тестовый игрок, а не бот с платным API ИИ. Он запускает реальную игру через Playwright (Chromium), использует **отдельный браузерный контекст** и не обращается к личным сохранениям игроков.

## Что он делает

- Проходит стартовый сценарий: создание нового героя, выбор фракции и имени.
- Проверяет карту и главное меню, убеждается, что подменю **скрыты до нажатия**, раскрывается ровно одна панель, а сама панель находится слева от основного меню.
- Ищет доступное существо по данным игровой карты и начинает обычный бой игровым методом. Ходы внутри боя выполняет **встроенный автопилот самой игры**. Результат боя определяется игровым движком, награды не подменяются.
- Проверяет экран результата, возвращение на карту и сохранение после перезагрузки.
- Запускает интерфейс на английском на телефоне, а в полном режиме — ещё и в альбомной ориентации.
- Сохраняет JSON-, Markdown-отчёты и снимки экрана; в случае ошибки тест завершается с ненулевым кодом.

**Ограничение первой версии:** бот ещё не выбирает ходы на поле match-3 самостоятельно, не открывает всю цепочку построек и не имитирует реальные касания по карте. Он выбирает противника через игровое состояние, а бой отдаёт игровому автопилоту. Так мы получаем воспроизводимую основу, которую затем можно развивать.

## Как запускать

В корне репозитория:

    npm ci
    npx playwright install chromium
    npm run test:player

Это короткий режим: один бой на компьютере и проверка меню на английском на телефоне.

Для расширенной проверки (два боя, в том числе проверка после загрузки, и дополнительная проверка альбомного экрана):

Linux/macOS:

    WIP_PLAYER_MODE=full npm run test:player

Windows PowerShell:

    $env:WIP_PLAYER_MODE='full'; npm run test:player

Отчёты: test-results/game-player/report.md, report.json и изображения PNG.

Можно запускать против локально поднятой игры через переменную WIP_URL (без адреса использует локальный index.html). **Не запускайте тесты на настоящем аккаунте**: тестовый сценарий создаёт новый профиль в изолированном браузере.

## GitHub Actions

Workflow: .github/workflows/game-player.yml.

- При изменениях кода в ветке main запускается короткий smoke-тест.
- Ночью (03:17 UTC) запускается расширенный тест.
- В разделе GitHub **Actions → Game player — browser smoke and full journey → Run workflow** можно вручную выбрать smoke или full.
- После запуска в карточке выполнения откройте **Artifacts → game-player-report** — там отчёт и скриншоты.
- Если запуск красный, смотрите шаг Run test player и report.json / failure*.png.

Если в репозитории Actions отключены организационными настройками, включить их может владелец. Зелёный результат означает прохождение именно описанных сценариев, **не доказательство отсутствия всех игровых ошибок**.

В проекте уже существуют дополнительные проверки: npm run test:e2e, npm test, npm run career. Они дополняют автоматического игрока.
