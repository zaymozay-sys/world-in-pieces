# Графика: спецификация файлов

Промты для ChatGPT — на странице «Арт-промты Хрупкого мира». Здесь — какие файлы ждёт игра и как их подготовить.

- Формат: PNG. Спрайты — на прозрачном фоне (настоящий альфа-канал, без нарисованной шахматной клетки), текстуры и фоны — на весь кадр.
- Текстуры должны стыковаться без швов.
- Размер — как отдаёт ChatGPT (квадрат 1024×1024, вертикальная 1024×1536, горизонтальная 1536×1024); при подключении картинки уменьшаются и сжимаются.
- Цвет уровня (Красный … Обсидиановый) игра добавляет сама: на вещах, существах и ресурсах его быть не должно.
- Файлы кладутся в папку `art/` по путям из таблицы. Чего нет — игра рисует по-старому.
- Пользователь может присылать картинки под любыми именами (ChatGPT называет файлы сам): при подключении они узнаются по содержимому и раскладываются по этим путям.
