# Передача проекта: «Хрупкий мир» (World in Pieces)

Этот файл — всё, что нужно новому помощнику (человеку или ИИ), чтобы продолжить разработку с того же места.
Версия на момент составления: **1.5.9** (см. `package.json`). Владельцы: Воробьев Александр Сергеевич, Никифоренко Екатерина Эдуардовна
(см. `LICENSE`). Общаться с владельцем нужно по-русски, коротко и по делу.

## Что это
Браузерная RPG «три в ряд» на поле 6×6: карта из шестиугольников с деревней, бой против существ (ИИ ходит сам), 4 фракции
(люди, гномы, эльфы, ящеры), снаряжение, магия, питомцы, медали. Чистый HTML/CSS/JS без сборки; выкладывается на GitHub Pages
(репозиторий `world-in-pieces`). Мир, графика и названия полностью свои; чужие игры не копируем.

## Главный документ
**`docs/design.md`** — полное описание: правила боя, фракции, монстры, экономика, история всех версий и решения владельца.
Читайте его первым. Графика: `docs/art-spec.md` (какие файлы ждёт игра), баланс: `docs/balance.md`.

## Структура
- `index.html`, `css/style.css` — страница и оформление (три варианта боя; по умолчанию №3 «колонки»).
- `js/` — модули игры. Ключевые: `engine.js` (поле и правила, без интерфейса), `combat.js` (бой), `ai.js` (противник),
  `balance.js` (все числа), `game.js` (экран боя), `mapview.js`/`hexmap.js`/`mapart.js` (карта и деревня),
  `screens.js` (окна зданий, стена доблести), `tutorial.js` (обучение у Бобра), `ammo.js` (боеприпасы), `market.js` (Торговые ряды), `story.js` (стражи и сюжет), `inventory.js` (профиль и сохранение в localStorage), `items.js`/`tiers.js`/`parts.js`
  (вещи), `bestiary.js`/`monsterart.js` (существа), `art.js` + `art-files.js` (подключение готовых картинок).
- `art/` — готовые картинки (WebP). Где файла нет — игра рисует встроенные SVG-заглушки.
- `tests/` — тесты, `tools/` — инструменты, `docs/` — документация и снимки для README.

## Как работать
- Запуск: открыть `index.html` в браузере (сервер не нужен). Тесты: `npm test` (18 наборов, должны проходить все).
- Подключить новую графику: положить PNG в папку, затем `python3 tools/build-art.py <папка>` (нужны Pillow и scipy). Имена
  файлов берутся из `docs/art-spec.md`; скрипт сжимает в WebP, раскладывает по `art/` и перезаписывает `js/art-files.js`.
- Проверка в браузере: `node tools/smoke.js` (страница без ошибок), `node tools/screenshots.js` (обновить снимки в `docs/`).
  Нужен Playwright.
- Одностраничный просмотр: `python3 tools/bundle.py` создаёт `gem-match-preview.html` (картинки внутри).
- Баланс: `node tools/balance.js --n=60 --tiers=1,4,7,10`; цель — «Равный» бой ≈ 55–80% побед, разброс между фракциями
  не больше ~5 пунктов; после правок магии, монстров и расходников всегда пересчитывать.

## Правила владельца (обязательные)
- Версия всегда из трёх цифр вида 1.3.4: последняя цифра 0–9, после 9 растёт средняя (1.3.9 → 1.4.0). Двузначных чисел (1.2.13) быть не должно. Пакеты 1.2.10–1.2.13 переименованы в 1.3.0–1.3.3.
- Поле с камнями не должно сдвигаться во время игры ни от каких действий (подсказки, сообщения, обучение, кнопки): оно стоит на одном месте.
1. **Версии идут подряд, прибавляя по единице к последней цифре. После 1.1.x — 1.2.0, дальше 1.2.1, 1.2.2…** (решение владельца). Ничего не пропускать.
   Число в `package.json`, имя архива `world-in-pieces-v<версия>.zip`, тег на GitHub `v<версия>`.
2. **Каждый выпуск отдаётся комплектом:** полный архив + части меньше 100 файлов каждая (лимит загрузки GitHub через
   сайт; с 1.2.8 частей четыре — картинок стало больше) + этот файл `HANDOFF.md` отдельным файлом для скачивания + обновлённое описание `docs/design.md`.
3. Подписи при загрузке на GitHub: `v<версия> (1/4): код и тесты`, `(2/4): графика героев и вещей`, `(3/4): существа, собеседники,
   руны, магия, ресурсы, камни`, `(4/4): карта и интерфейс`; потом релиз с тегом `v<версия>`. Предпросмотр (`tools/bundle.py`)
   ужимает крупные картинки только в своей сборке — лимит артефакта 16 МБ.
4. Любое изменение — с тестом; не ломать старые сохранения (профиль дополняется недостающими полями).
5. Не копировать чужие игры (названия, картинки, раскладки) — только вдохновляться.
6. Править именно то, что просили. Если трактовка неясна — спросить, а не угадывать (ошибка с «обсидианом ×5» заняла четыре
   попытки именно из-за неверной трактовки).
7. Названия и тексты в игре — по-русски. Репозиторий и заголовок README — английское имя `World in Pieces`.

## Что важно знать про правила боя (самое хрупкое)
- **Обсидиан ×5** — камень обсидиана с номиналом x5, собранный в любой линии: в том же проходе убирает все камни вокруг на
  расстоянии 1 (до 8, с диагоналями), потом камни падают и сдвигаются вправо. За соседей — ресурсы; урон — только за
  соседей-обсидиан (или при активной Шаровой молнии). Цепная реакция между соседними x5. Код: `Engine.obsidianBurst`.
- Камни после сбора падают вниз, затем сдвигаются вправо; новые появляются, только когда поле пусто или нет ходов.
- Линия 4+ даёт дополнительный ход (4 — x2, 5 — x3, 6 — x10). Неверный ход — штраф 5% ХП; 3 подряд — поражение. Ход — 30 секунд.
- Магия: у каждого заклинания своя цена (`Balance.magic.costs`), часть открывается по уровню героя.
- Дикий гриб: настоящий двойник (второй противник) по заряду спор. Питомцы: настоящий бой 2 на 1.

## Языки (русский и английский) — с 1.4.7

- Любой текст для игрока в коде пишется через `_t('Русский текст')` или со вставками `_t('Получено {0} монет', [n])` (вместо `{0}`, `{1}` подставляются элементы массива). Без `_t` текст останется русским и в английской версии.
- Английские переводы — в `js/en.js`: ключ — русская строка из кода, значение — перевод. Правка перевода = правка значения в этом файле, код трогать не нужно. Нет перевода — игра покажет русский.
- Надписи в `index.html` (кнопки, подсказки) переводятся автоматически по тому же словарю (ключ — текст с одним пробелом между словами).
- Язык: выбор игрока (кнопка «EN/RU» на карте, хранится в localStorage `wip-lang`) → язык браузера (ru/uk/be/kk → русский, остальное → английский). Для площадок (Яндекс Игры, VK): до загрузки скриптов задать `window.WIP_LANG = 'ru' | 'en'`. Переключение перезагружает страницу.
- Проверка: `node tools/i18n-extract.js` (нужен acorn: `ACORN_PATH=путь/к/acorn`) показывает строки без перевода и русский текст вне `_t`; `tests/i18n.test.js` (в `npm test`) следит, чтобы у каждой строки был перевод с теми же `{0}` и HTML-тегами.
- Скрипты `i18n.js` и `en.js` стоят первыми в `index.html` и в сборке. Переводы сделаны сразу на весь текст; шутки и голоса героев стоит вычитать глазами в игре.
- Испанский добавляется так же: новый словарь `es.js` (по образцу `en.js`) и ещё одно значение в `i18n.js`.

## Бой с питомцем: два поля одновременно — с 1.4.8
- `js/game.js`: весь бой обёрнут в фабрику `createBattle(host)` (host: `main`, `root`, `role`, `id`, `sound`, `autopilot`, `autoLevel`, `coord`). Основной экземпляр `MAIN_BATTLE` на странице; его API (все top-level имена, блок `Object.defineProperties` в конце фабрики генерируется скриптом по списку объявлений) пробрасывается в `globalThis`, чтобы остальные файлы и тесты работали как раньше. Копия разметки для второго поля — `BATTLE_TEMPLATE` (клон `main.game`, взят до привязки основного боя). Новые top-level имена внутри фабрики нужно добавлять в этот блок.
- Второе поле — экземпляр с `role:'pet'` (`startPetGame`): боец-питомец (`isPet`, не колдует, ХП × `Pets.BOARD_HP` = 1.25) против точной копии противника героя. Автопилот (`autoTurn/kickAuto/setAutopilot`) ведёт нашу сторону через `AI.choose` на `autoLevel`.
- `Duo` (конец game.js): вкладки «Герой / Питомец» (`.duo-bar`, фикс. сверху), кнопка «Играть за питомца» / «Играть за героя»; `ended/evaluate/finish`: выживший добивает оставшегося противника (`adoptFoe/resumeAfterAdopt`), награда за каждого убитого (`grantDuoRewards/rewardFor`) при победе, поражении и отступлении (`flee`), опыт питомца (`petGrowth`). Если играем за питомца — героя ведёт ИИ на 100.
- Питомец дома/в бою: `Profile.petStay/petInBattle`, чекбокс на карточке монстра (mapview.js), переключатель в Питомнике. Обучение, Бобёр и стражи осколков — без питомца на поле (прежнее поведение).
- Ум питомца: `Pets.intellect(pet)` 1..100 по опыту (`pet.xp`; на 100 — максимальная глубина разбора, `AI.settings`); цвет растёт от опыта (`Pets.addXp`, не выше цвета героя); допинг: угощения +8/+25 к уму на бой (`Pets.dopedIntellect`, `pet.intBonus`). В Питомнике — «ум N/100 · опыт X».
- Тесты: юнит — `tests/pets.test.js` (ум, опыт, допинг); сквозной в браузере — `NODE_PATH=$(npm root -g) npm run test:duo` (`tests/duo.e2e.js`: два поля, вкладки, смена управления, отступление, полный бой с наградой/опытом, питомец дома). Проверено: `npm test`, smoke, Playwright (автопрогон двух полей, переключение управления, отступление), скриншоты десктоп/телефон. Не проверено: реальный телефон, баланс слабого питомца.
